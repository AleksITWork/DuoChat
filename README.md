# DuoChat

Мобильное приложение для обмена сообщениями между двумя пользователями.

## 📱 Описание

DuoChat - это приложение, разработанное для ОС Android в рамках курсового проекта по дисциплине
МДК 01.03 "Разработка мобильных приложений". Приложение позволяет пользователям регистрироваться,
авторизовываться, изменять данные о себе, находить друг друга и обмениваться сообщениями в реальном
времени.

## 🚀 Возможности

### Обязательно к реализации
- [ ] Регистрация пользователей
- [ ] Авторизация пользователей
- [ ] Изменение данных пользователем
- [ ] Поиск других пользователей
- [ ] Создание чатов с другими пользователями
- [ ] Отправка и получение текстовых сообщений
- [ ] Локальное кеширование данных

### Возможна реализация
- [ ] Отправка аудио- и видео-контента другим пользователям
- [ ] Индикация "онлайн"
- [ ] Статус "прочитано"/"не прочитано"
- [ ] Получение push-уведомлений

## Технологии и стек

- **Язык программирования**: Kotlin
- **UI-составляющая**: Jetpack Compose
- **Локальная БД**: SQLite + Room
- **Удаленная БД**: Firebase Cloud Firestore
- **Авторизация**: Firebase Authentication
- **Навигация**: Jetpack Navigation Compose
- **Архитектура**: MVVM

## 📦 Установка

### Требования

- Android Studio Quail 4 или новее
- Android SDK 34
- Kotlin 1.9+
- Устройство или эмулятор с Android 8.0+ (API 26+)

## Шаги установки

1. Клонируйте репозиторий
```bash
git clone https://github.com/AleksITWork/DuoChat.git
```
2. Открыть проект в Android Studio
3. Синхронизировать Gradle и запустить приложение
